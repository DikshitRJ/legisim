# Visualization Upgrades Plan

## 1. Overview
The prototype heavily relies on Recharts for simple charts and CSS grids for maps. For the production version, we are migrating to Apache ECharts, MapLibre GL, and standardizing our React Flow implementation.

### Recommended Subagents
- `ui-builder`: For ECharts wrapper and MapLibre GL integrations.
- `animation-specialist`: To verify that framer-motion page transitions do not conflict with Canvas-based ECharts rendering.

## 2. Apache ECharts Migration

### 2.1 EChart Wrapper Component
Create `/src/components/charts/EChartWrapper.tsx` to handle the `chart_spec` sent from the AI agent.

```typescript
'use client'
import ReactECharts from 'echarts-for-react';
import * as echarts from 'echarts';

// Define the theme once
echarts.registerTheme('legisim-theme', {
  color: ['#FF9933', '#138808', '#000080', '#F5F5DC', '#333333'], // Saffron, Green, Navy, Canvas
  backgroundColor: 'transparent',
  textStyle: { fontFamily: 'Inter, sans-serif' }
});

interface EChartWrapperProps {
  option: echarts.EChartsOption;
  height?: string;
  className?: string;
}

export function EChartWrapper({ option, height = '400px', className }: EChartWrapperProps) {
  return (
    <ReactECharts 
      option={option}
      theme="legisim-theme"
      style={{ height, width: '100%' }}
      className={className}
      opts={{ renderer: 'svg' }} // Use SVG for better crispness and accessibility
    />
  );
}
```

## 3. MapLibre GL + deck.gl setup
The prototype uses a static grid for the "Map" tab. We will replace this with a real geographic map of India.

### 3.1 Setup
Install dependencies:
`npm install maplibre-gl deck.gl @deck.gl/react @deck.gl/layers`

### 3.2 Implementation (`/src/components/map/DeckGLMap.tsx`)
```typescript
import React from 'react';
import DeckGL from '@deck.gl/react';
import { GeoJsonLayer } from '@deck.gl/layers';
import Map from 'react-map-gl/maplibre';
import 'maplibre-gl/dist/maplibre-gl.css';

const INITIAL_VIEW_STATE = {
  longitude: 78.9629,
  latitude: 20.5937, // India center
  zoom: 4,
  pitch: 45,
  bearing: 0
};

export function ImpactMap({ geoData }: { geoData: any }) {
  const layers = [
    new GeoJsonLayer({
      id: 'impact-layer',
      data: geoData,
      pickable: true,
      stroked: true,
      filled: true,
      extruded: true,
      getFillColor: d => d.properties.impact > 0 ? [19, 136, 8] : [255, 153, 51], // Green vs Saffron
      getElevation: d => Math.abs(d.properties.impact) * 1000,
      elevationScale: 10,
    })
  ];

  return (
    <div className="relative w-full h-[600px] rounded-xl overflow-hidden shadow-lg border border-border">
      <DeckGL
        initialViewState={INITIAL_VIEW_STATE}
        controller={true}
        layers={layers}
        getTooltip={({object}) => object && `${object.properties.name}\nImpact: ${object.properties.impact}`}
      >
        <Map mapStyle="https://basemaps.cartocdn.com/gl/positron-gl-style/style.json" />
      </DeckGL>
    </div>
  );
}
```

- Integrate `shadcn/ui` components (Select, Tooltip, HoverCard) for filter controls above the visualizations.
- Ensure the saffron (`#FF9933`) and green (`#138808`) colors maintain a contrast ratio of at least 4.5:1 against the canvas background.
