# Ripple Graph API Documentation

This API domain provides access to the causal ripple graphs generated by policy simulation runs. The ripple graph visualizes how primary policy shocks propagate through various economic and social domains over time.

## Overview

The primary interface for this domain is a read-only endpoint that retrieves the entire ripple graph for a specific simulation run, consisting of Nodes and Edges.

## Endpoints

### Get Ripple Graph
`GET /api/runs/{runId}/ripple`

Retrieves the complete ripple graph for a specified simulation run.

**Path Parameters:**
- `runId` (string, required): The unique identifier of the simulation run.

**Response:**
Returns a JSON object containing two arrays: `nodes` and `edges`.

**Example Response:**
```json
{
  "nodes": [
    {
      "id": "node-123",
      "label": "Fuel Price Increase",
      "layer": 0,
      "domain": "policy",
      "magnitude": "+10%",
      "confidence": "high",
      "kind": "measured"
    },
    {
      "id": "node-456",
      "label": "Freight Transport Costs",
      "layer": 1,
      "domain": "transport",
      "magnitude": "+4%",
      "confidence": "medium",
      "kind": "modelled"
    }
  ],
  "edges": [
    {
      "id": "edge-789",
      "source": "node-123",
      "target": "node-456",
      "strength": 0.85,
      "lagMonths": 1,
      "mechanism": "Higher diesel costs pass through to truck fleet operators directly."
    }
  ]
}
```

## Data Types

### Ripple Node
Represents a specific event, state change, or impact in the causal chain.
- `layer`: The depth in the causal chain. Layer 0 is the direct policy action.
- `domain`: Categorizes the node (e.g., `policy`, `transport`, `agriculture`, `economy`, `health`, etc.).
- `confidence`: `high`, `medium`, or `low`.
- `kind`: `measured` (from official data), `modelled` (computed deterministically), or `judged` (LLM-reasoned).

### Ripple Edge
Represents the directed causal link between two nodes.
- `strength`: A numeric value indicating the magnitude and direction of the causal effect.
- `lagMonths`: The temporal delay before the effect is felt.
- `mechanism`: A text explanation of why and how the source node affects the target node.
