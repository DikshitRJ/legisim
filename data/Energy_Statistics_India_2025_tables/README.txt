Energy Statistics India 2025 — one CSV per table
Ministry of Statistics and Programme Implementation (MoSPI)
National Statistics Office. Released 27 March 2025.

The file you uploaded is a compressed scan of this publication (no text layer).
These CSVs are the same tables, taken from the official text edition of that
release so the figures are not OCR guesses. Multi-page tables are kept in one
file and are not split.

How the folders are labelled
  01 to 09     chapters of the publication
  Annexure I   coal grade definitions
  Annexure II  measurement units and conversion factors
  Annexure IV  energy balance, one file per year, 2012-13 to 2021-22

Each CSV
  Row 1        table title
  Row 2        unit and publication page, when printed
  Then a blank row, the column headings, and the data
  Notes from the foot of the table follow the data
  Files are UTF-8 with a BOM so Excel keeps the text correctly
  Thousands separators have been removed so the figures open as numbers

69 numbered tables from the List of Tables are included.
Tables that continue on the next page are one file:
  Table 2.1  pages 19-20
  Table 4.1  pages 43-44
